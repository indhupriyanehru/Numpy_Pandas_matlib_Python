# Student Performance Analysis Using Python

## Project Overview
This project analyzes student performance across five subjects using Python, NumPy, Pandas, and Matplotlib. It calculates descriptive statistics, identifies top-performing students, assigns grades, and visualizes academic performance.

## Technologies Used
- Python
- NumPy
- Pandas
- Matplotlib

## Features
- Store and analyze marks for 10 students across five subjects
- Calculate total marks and student averages
- Calculate subject-wise mean, median, maximum, and minimum
- Calculate standard deviation and variance
- Filter students based on marks and average scores
- Sort students by total marks and generate rankings
- Assign grades and count students in each grade
- Export student data to a CSV file
- Visualize mark distributions and subject comparisons

## Learning Outcomes
This project demonstrates foundational skills in numerical computing, data manipulation, descriptive statistics, data filtering, ranking, CSV export, and data visualization.
